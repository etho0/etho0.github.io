URL Scheme Launch Matrix

Tests which URL schemes launch external apps from a web page, and via which injection method. Safari is supposed to block subframes from launching apps (Safari 9+ restriction), but Apple's built-in telephony schemes (facetime://, tel://) appear to bypass this.

The critical question: do all registered URL schemes launch from iframes, or only Apple's built-in ones? If shortcuts:// launches from an iframe without prompt, a web page can execute arbitrary automation on the user's Mac.

This probe launches external apps on your system. Only run on your own device. Each test opens one app — close it and return to continue.
