Activation Laundering

Tests whether the host application supplies user activation to embedded content. Established on macOS WKWebView: an in-page call to a gated API fails with InvalidStateError — must be called from a user gesture handler, while the same call driven by the host's own evaluateJavaScript succeeds. If a container injects JS for routine events (theme, viewport, bridge replies), content can register a handler on those events and call a gated API inside the borrowed activation window — with no user interaction at all.

Probe target: showOpenFilePicker (file read). Nothing is read or uploaded — the test records only whether the picker was allowed to open, then aborts.
