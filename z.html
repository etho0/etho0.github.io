Zero-Gesture File Picker

Tests whether a Mini App receives user activation it never earned — inherited from the native "Open App" tap — and whether that is enough to open a file/directory picker on load with no interaction inside the page.

Key instrument: navigator.userActivation. If isActive is true at t=0 while the page has received no events, the container handed activation to attacker-controlled content.

Order: ?first=dir (default) · file · input. Each attempt consumes transient activation, so only the first is a clean test — re-open the Mini App to try another.
