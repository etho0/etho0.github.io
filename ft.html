URL Scheme Probe

Tests whether this WebView context intercepts or passes through facetime://, facetime-audio://, and tel:// URL schemes.

Context: Safari intercepts these with a confirmation dialog. WKWebView delegates to the host app's decidePolicyForNavigationAction. Apps that don't explicitly filter facetime:// let FaceTime open with camera preview — no web permission involved.

Prior art: NowSecure 2017 — LinkedIn, Twitter confirmed vulnerable. CVE-2014-7305 (Mercury Browser).
