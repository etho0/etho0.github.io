Persistent File Access

A FileSystemHandle is structured-cloneable, so it survives in IndexedDB. If queryPermission() still returns granted on a later visit, the content is readable with no picker, no gesture and no prompt — on every subsequent open of the Mini App.

In a browser, Chrome shows persisted file access in the omnibox with a control to revoke it. A Mini App WebView has no omnibox — no indicator, no revoke path.

Step 1 runs once and needs one interaction. Step 2 runs automatically on every load — that is the finding.
